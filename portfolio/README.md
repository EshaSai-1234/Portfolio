## 🌟 Key Features

- **🎨 Modern White Theme**: Crisp white background (`#ffffff`), soft slate canvas (`#f8fafc`), clean typography (`Plus Jakarta Sans` & `Inter`), and subtle multi-layer drop shadows.
- **⚡ Single-Page Application (SPA)**: Smooth scroll navigation across all sections (`#home`, `#about`, `#experience`, `#projects`, `#certifications`, `#stats`, `#contact`) with automatic scroll-spy navbar highlighting.
- **🎓 Academic Timeline**: Visual vertical timeline showcasing education at **VIT-AP University** (CGPA: 7.70), **Narayana Junior College** (98.7%), and **Narayana Concept School** (98.3%).
- **💼 Work Experience**: Dedicated section highlighting open-source contributions at **GirlScript Summer of Code (GSSoC)** and virtual job simulations across **Deloitte, BCG, Accenture, PwC, Wells Fargo, Citi, HP, and Commonwealth Bank**.
- **🚀 Featured Projects**: Interactive cards detailing AI/ML, NLP, LLMs, Reinforcement Learning, Next.js, React, and MERN stack applications:
  - *Weather Web App using React*
  - *Course Recommendation & Learning Analytics Bot (NLP, LLMs, LangChain)*
  - *Reinforcement Learning Based Stock Trading System (DQN & PPO)*
  - *AI Multimodal Customer Churn & Sentiment Analysis*
  - *Inventory Management System (Next.js & TypeScript)*
  - *AI-Based E-commerce Product Recommendation System*
  - *Product Review System (MERN Stack)*
  - *Data Analytics Power BI Dashboard*
- **🏅 Certifications & Credentials**: Badges for **Google Cloud Skill Badges**, **GEN AI using IBM Watsonx**, and **Coursera NLP using TensorFlow**.
- **📊 Coding Contributions & Stats**: Clean metric cards displaying GitHub statistics (46 Repositories, 206+ Contributions) and competitive programming milestones (160 LeetCode, 60 GeeksforGeeks, 60 CodeChef).
- **📬 Interactive Contact Section**: Contact cards for Email & Phone with **1-click Copy-to-Clipboard** feedback toasts, plus a functional direct message contact form.

* **HTML5**: Semantic web markup and structured layout.

## 🚀 Quick Start / Local Setup

You can run this portfolio locally using any static web server or Python's built-in HTTP server:

### Option 1: Python Built-in HTTP Server
```bash
# Navigate to the portfolio directory
cd portfolio

# Start local server on port 8080
python -m http.server 8080
```
Open **[http://localhost:8080](http://localhost:8080)** in your web browser.

### Option 2: Live Server / VS Code
Open the project directory in VS Code and click **"Go Live"** using the Live Server extension.
